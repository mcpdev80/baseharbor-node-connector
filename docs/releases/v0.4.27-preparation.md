# BaseHarbor Node Connector — v0.4.27 release preparation

> Draft. No v0.4.27 native compatibility is claimed.

## What users should know

Node Connector is optional access to remote non-Kubernetes runtime hosts. It is a separate component, **not** a required part of connecting a developer workstation to BaseHarbor Core. Keep this distinction clear in the release announcement and setup documentation.
