# BaseHarbor Node Connector and v0.4.27

Node Connector enables secure access to remote Docker and Podman runtime hosts through the Target Access Provider. It maintains a bounded transport and enrollment role. Core remains responsible for application state, ownership, policy and lifecycle decisions.

A developer workstation does not need Node Connector simply to access remote Core. The Connector is used only when a remote runtime host is enrolled.

See the [Connector overview](../../README.md), [integration records](../RELEASE-INTEGRATION.md) and [BaseHarbor v0.4.27 release notes](https://github.com/mcpdev80/baseharbor/blob/develop/docs/releases/v0.4.27.md).
